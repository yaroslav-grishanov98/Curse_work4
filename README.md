# Django Mailing Service

Веб-приложение для управления рассылками сообщений клиентам, реализованное на Django.

## Описание

Приложение позволяет:

- Управлять клиентами (получателями рассылок)
- Создавать и редактировать сообщения
- Создавать, редактировать и запускать рассылки
- Отслеживать попытки отправки сообщений
- Регистрация и аутентификация пользователей с подтверждением email
- Разграничение прав доступа между обычными пользователями и менеджерами
- Автоматическая отправка рассылок по расписанию
- Логирование и кеширование для повышения производительности

## Установка

1. Клонировать репозиторий
2. Создать виртуальное окружение: `python -m venv .venv`
3. Активировать окружение: 
   - Windows: `.venv\Scripts\activate`
   - Linux/Mac: `source .venv/bin/activate`
4. Установить зависимости: `pip install -r requirements.txt`
5. Применить миграции: `python manage.py migrate`
6. Запустить сервер: `python manage.py runserver`

## Ветки

- `main` - основная ветка с релизами
- `develop` - ветка разработки
- `feature` - ветка для выполнения домашнего задания


## Логирование
Логи сохраняются в файл logs/app.log (если настроено в settings.py).

Структура проекта
config/ — настройки Django проекта
service/ — основное приложение с логикой рассылок и пользователями
templates/ — шаблоны HTML
.env — файл с конфиденциальными настройками (не добавлять в git)
requirements.txt — зависимости проекта
